# 💸 Expense Tracker

A simple and responsive expense tracker built with **HTML, CSS, and JavaScript**. It allows users to manage their income and expenses, calculate their balance, search expenses, filter them by category, and keep their data saved using LocalStorage.

## ✨ Features

* 💰 Add income
* 💸 Add expenses
* ✏️ Edit expenses
* 🗑️ Delete expenses
* 📊 Automatically calculate:

  * Total Balance
  * Total Income
  * Total Expenses
* 🔍 Search expenses by name
* 🏷️ Filter expenses by category
* 💾 Save data using LocalStorage
* 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 🚀 How It Works

Users can add their income and expenses through the provided forms. The application automatically updates the total income, total expenses, and remaining balance.

Expense data is stored in the browser using **LocalStorage**, so the data remains available even after refreshing the page.

Users can also search for specific expenses or filter them by category.
